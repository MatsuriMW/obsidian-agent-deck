# Agent Deck 1.9.7 验证记录

日期：2026-11-15。基于已发布的 1.9.6，补充摘要短链与自动记录 token 显示修复。

## 公共规则

所有 Agent 客户端读取数据后，共用任务与结论写入规则。长地址显示为 `[🔗](完整地址)`，已有清楚的链接文字保留。缩短正文时保护完整链接，文件路径中的空格、括号可正常编码；原始对话归档和详细摘录保留原文。

用户修改的标题继续按原文保留，完成及归档时清理内部标识。公共规则不根据客户端名称或所用模型单独分支。

新增参数化测试覆盖 Claude、Codex、DeepSeek Harness、WorkBuddy、Antigravity、OpenCode 和 Qoder。验证短链、任务及结论含义、用户标题、重复扫描和完成清理。此项覆盖公共处理规则，不代表本次重新实测了七家客户端的全部委派流程。

## token 显示

螺旋日程必须实际返回同一会话并提供对应 token，Agent Deck 才让出显示。无法接管时，由 Agent Deck 显示 token 数字及数据库图标。不活跃会话也合成界面所需的 token 数值，沿用输入加输出、缓存另计的口径。

本机升级后，两个实际自动记录条目恢复 token 数字和 SVG 数据库图标。用量数据保持原样，没有估算客户端未提供的 token。
