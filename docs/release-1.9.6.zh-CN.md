# Agent Deck 1.9.6 验证记录

日期：2026-11-15。包含此前尚未发布的协作回顾和语义标识改动。

## 实验回顾

设置新增“实验功能”页，AI 协作回顾默认开启。关闭后隐藏侧栏入口和命令、关闭已打开的回顾页；保留历史统计及项目归属更正。重载后继续保持关闭，再次开启可正常打开。

回顾基于已保存的本机数据，提供 token 热力图、日期筛选、项目投入、记录明细、来源跳转及归属更正。缺失数据不作估算，回顾不调用模型、不改写日记。

## 语义标识

新任务使用 Agent 前缀、一两个英文任务关键词和 10 位短尾码。中文短名复用已配置的整理模型；自动记录在原有命名调用中同时生成。已有块号保持不变，改标题或换模型不换号，翻译失败时使用短码继续追踪。

内部标识在正常编辑和阅读时隐藏，原始 Markdown 仍保存。DONE、会话归档及整理已完成日志时清理内部块号和记录注释，保留会话链接、手写内容、代码示例及仍在进行的子任务。

## 标题与确认消息

用户修改的标题按原文保留，暂停、完成和整理不再清洗标题。确认选项回传提取可读答案，避免内部 XML 标签和 JSON 键进入记录。带来源标记的已生成异常任务字段可修正，结论和手写内容保留。

## 验证

- 本地完整 `npm test`、`npm run build` 和 `git diff --check` 通过。
- 新增实验开关的默认值、持久化、关闭回顾页、禁用打开入口、数据保留和保存失败恢复测试。
- Obsidian 实测五个设置页和默认开启状态。关闭后侧栏入口与命令不可用，打开的回顾页关闭；重载后保持关闭，再开启可恢复打开。
- 语义短名已用当前配置的整理模型实测；验证重命名稳定、并发请求复用、委派绑定、结果回写及完成后清理。
- Qoder 已实测本机后台委派、同一会话终端续聊、两轮结果追踪与回写、完整原文归档。读取本机桌面数据库时无扫描错误。

本次验证不代表七家客户端的全部委派方式均已实测。Qoder CLI 与桌面会话仍分开；桌面交接需要用户粘贴并发送任务。
