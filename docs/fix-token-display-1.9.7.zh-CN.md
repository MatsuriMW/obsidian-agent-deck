# Fix Report：自动记录条目的 token 显示消失

## 根因与复现

Agent Deck 按螺旋日程的设置和任务状态判断“已接管”，提前隐藏自己的条目显示。螺旋日程没有匹配到会话时也不显示，导致 token 数字和数据库图标消失。

另一个缺口是不活跃会话不在实时快照中，备用元数据有输入与输出计数，却没有给界面合成 `tokens` 字段。数据本身仍然存在。

`node --test test/token-display.test.mjs` 在修复前复现这两处缺口。实际 Obsidian 中，两个自动记录条目具有用量数据，却没有可见 token 控件。

## 修复

只有螺旋日程确实返回同一会话，且能够表示对应 token 时才让出显示；否则由 Agent Deck 显示 token 数字和数据库图标。不活跃会话按原有口径合成输入加输出，缓存继续单独统计。

没有修改螺旋日程源码，也没有删除、估算或重算用量。

## 验证与依据

检查了条目绑定、实时会话与元数据、编辑器装饰和第三方接管判断。核对 [Obsidian API 类型声明](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts) 中的编辑器扩展和图标接口，并以当前安装的螺旋日程 `lineStatus` 返回值作为实际接管证据。

新增测试覆盖未接管、接管不同会话、未提供 token、成功接管和不活跃会话。完整回归通过。本机安装后，两条记录恢复 token 数字及 SVG 数据库图标。

判断只读取现有会话数据及缓存，不增加磁盘扫描或模型调用。经验：第三方插件启用了某项设置，不等于它已经成功显示了当前条目。
