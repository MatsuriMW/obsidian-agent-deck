# 共享 Dream 长期记忆契约

> v1 契约（整份快照）。下一步的"按条共享 + MCP 接入"方向见 [`dream-shared-memory.md`](dream-shared-memory.md)，尚未实现，不改变本文件语义。

## 单向共享语义
- **数据源与导出**：读取最近 14 天日记及委派任务笔记提炼记忆，写入 `Agent Deck/长期记忆.md`；共享快照导出到用户配置的专用 Markdown 路径（支持 Mac / Windows 绝对路径与 `~/`）。
- **单向覆盖**：共享快照每次覆盖目标文件（保留人工前置说明、当前有效记忆与来源，排除已拒绝/已替代条目）；其他 Agent 修改记忆需回改原 Obsidian 长期记忆笔记后再同步。
- **调度独立**：定期同步（1–168 小时，失败至少间隔 1 小时重试）独立于「每天自动整理」，仅在插件运行期触发。

## Git 推送与外部插件隔离
- **最小提交范围**：开启「同步后提交并推送 Git」时，插件**只提交该共享文件**并推送至 `origin` 同名当前分支，严禁夹带仓库内其他暂存/未暂存修改；内容无变化时不新增提交但仍重试推送；冲突或失败保留本地文件与错误状态，不自动 merge。
- **Telegram Companion 联动**：仅在运行时检测到已安装该插件时显示开关；实际同步要求 Companion 已启用且档案已创建，且只更新 Agent Deck 专属区段，不覆盖手写档案内容，不直接发 Telegram 消息。
