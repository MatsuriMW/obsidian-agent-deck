# 关键技术坑与约束

- **EditorSuggest 抢占顺序**：Obsidian 按注册顺序命中即返回，加载时需将窄范围 `@` 补全重排到内部 `suggests` 列表前列，卸载时按对象移除（升级 Obsidian 需复测未公开 `suggests` 数组）。
- **第三方让渡看实际渲染**：螺旋日程开启开关不等于成功显示当前条目；必须以 `lineStatus` 实际返回同一会话且含 token 为准，否则不得让出，且不活跃会话需从备用元数据合成输入+输出 token。
- **锁外等待模型 + 局部扫描**：LLM 调用在按文件写入锁外执行，返回后校验笔记变更并避开 IME 组字；长日志同步缓存块尾偏移、隐藏编号保护仅查受影响行，避免 O(N²) 全篇重扫。
- **控制消息与缓存同步**：Codex `send_user_message_question_reply` 与 DSH 系统注入走用户消息通道，统一由 `src/prompt-text.js` 提取可读确认或剥离注入，修改解析规则后**必须递增 `USAGE_CACHE_VERSION`**。
- **子进程输出与 ACP 权限**：Claude `stdout` 流式排水等 `close`、Qoder `exit` 不丢缓冲且不 trim 首尾空白、Codex 同轮多段回复按消息 ID 去重；ACP 权限 `optionId` 读服务端返回值，进程未返结果即退出（含 code 0）按失败处理，`finished` 阶段不阻断取消与清理。
- **会话隔离边界**：CodeBuddy CLI（`~/.codebuddy/projects`）与国内版 WorkBuddy 桌面（`~/.workbuddy`）、`qodercli`（`~/.qoder/projects`）与 Qoder 桌面 SQLite 均不互通，不可跨端续聊。
- **总结与标题保护**：普通会话不能截取回复开头代替总结或生成后硬截断；后台回答不再生成总结，按 500 字分流到完整原文或干净问答文件，不能把扫描器的截短预览当原文；保留用户改过的 AI 标题时必须跳过空格压缩与时间前缀剥离，并防止历史标记触发重排。
- **同名项目聚合与子代理等待降噪**：项目分组不能直接用末级目录名当键，必须以规范化根路径隔离并在同名碰撞时附加父目录区分；子代理 `turn/end` / `task_complete` 应标为 `done`（`aborted` 标 `cancelled`）并通过 `parentSid` / `parentCwd` 继承母会话项目，避免落入「独立会话」或污染「等你」列表。
- **macOS GUI 进程不继承终端代理**：Obsidian 桌面进程 `process.env` 不含 shell 的 `HTTPS_PROXY` / `ALL_PROXY`，导致 ACP CLI 连网静默超时；`cleanEnv()` 在未显式配置代理变量时必须通过 `/usr/sbin/scutil --proxy`（60s 缓存）读取系统 HTTP/HTTPS/SOCKS 代理并补全 `127.0.0.1,localhost,::1` 至 `NO_PROXY`。
- **Claude Code 子文件共 `sid` 与 Cursor 早退丢父子**：Claude Code `<parent>/subagents/agent-*.jsonl` 共享母会话 `fc.sid` 且带 `fc.sub`，绝不能扫 `files` 凭 `fc.sub` 判子代理或把子文件 `parentSid`/`isSubagent` 写回母会话；Cursor `ingestCursorEvent` 必须在 `sessionStart` 及带 token 的 `afterAgentResponse`/`stop` 提前 `return` 之前绑定父子关系。
- **动态 ACP 模型必须统一汇入 `allModels()`**：不得在 `allModels()` 硬编码部分 Agent 白名单，必须统一遍历 `settings.delegate` 收集 `availableModels`，否则 `refreshAcpModels` 拉回模型后设置页下拉框与 `modelsFor()` 仍看不到新模型。
- **Windows `.cmd` 拉起、TDZ 与跨插件粗体 `key` 匹配**：`checkBinary()` 必须使用 `spawnCli` / `killChildProcess`（避免 Windows `.cmd` 报 `EINVAL`），且 `timer` 必须在 `done()` 回调前声明以避开 TDZ `ReferenceError`；`autoLogState` 里的 `key` 带 `**...**`，与螺旋日程等配套插件对齐去重时必须同步剥粗规范化。
- **SQLite WAL 已 checkpoint 无 `-wal`/`-shm` 只读报 Error 14**：客户端正常退出后 SQLite 头部保留 WAL 标记但磁盘已无 `-wal`/`-shm` 伴生文件时，直接执行 `sqlite3 -readonly` 会报错 `unable to open database file (14)`；`desktopQuery` 必须在不存在非空 `-wal` 时通过 `toSqliteUriPath(db)` 走 `file://...?immutable=1`，并在存在非空 `-wal` 且 `-readonly` 失败时回退 `PRAGMA query_only = ON;`（附 `.timeout 2000`）。
- **聚合端 `delegatedOwners` 占位解码与局部扫描同步**：T3 Code 等投影字段可能写入 URL 编码的 `pending%3A...` 占位符或 `:native-thread:` 复合串，提取候选会话号前必须先 `decodeURIComponent` 再过滤占位前缀；此外，仅靠全量扫描维护 `delegatedOwners` 会漏掉首次主力推荐与单卡重扫，必须在 `initializePrimaryAgents` 和 scoped `scanNow` 中调用 `mergeDelegatedOwners`，并在强扫/`rebuildUsage` 时执行 `delegatedOwners.clear()`，设置页卡片统计也须过滤 `delegatedOwnerOf`。
- **Electron `shell.openExternal` 异步拒接吞错**：`shell.openExternal(url)` 返回的是 Promise，同步返回 `true` 无法感知系统未注册 URL Scheme（如 `cindy://`）；需要失败后降级唤起应用并弹出提示时，必须使用异步 `openExternalAsync(url)` 等待判定。
- **CM6 扩展事务参数遮蔽模块级 `t as tr`**：引入 `import { t as tr } from "./i18n.js"` 的编辑器扩展模块（如 `src/editor.js` 的 `dropField`）严禁把状态更新事务参数命名为 `tr`，统一使用 `tx`，否则会在调用 `tr(...)` 本地化文案时触发 `TypeError`。
- **圆圈徽标数字光学居中与混排基线对齐**：仅靠 `inline-flex` + `align-items: center` 会因字体半行距/下降部把数字压偏且基线漂移；内层数字包裹（`.ad-round-badge__num`）需设 `text-box-trim: trim-both; text-box-edge: cap alphabetic;` 做光学居中，并给徽标与 `.ad-agent-mark` 配置相对字号的 `em` 微调偏移（`top: -0.15em` / `-0.09em`）。
- **ACP 子进程排水、响应块数组与 Windows 系统代理**：`AcpRunner` 必须在子进程 `close`（而非 `exit`）后刷新尾行缓存以免丢失末帧 JSON-RPC 消息，`extractAcpText` 需兼容 `content` 文本块数组并剥除首行 `\uFEFF`，超时与早退错误应附带脱敏 `stderrTail`；Windows GUI 下无代理环境变量时经 `parseWindowsRegProxy`（`HKCU\...\Internet Settings`）注入系统代理并补全 `NO_PROXY`。
- **Kimi Code v2 子目录、`profile.bind` 与重复 token 记账**：Kimi Code v2 将消息流移入 `sessions/<wsHash>/<sid>/agents/main/wire.jsonl`（工作区索引改为 `projects.json`），且同一轮内 `step.end` 与紧随的 `usage.record` 会携带相同 token 账单；适配器须兼容多子代理目录、`profile.bind.modelAlias` 及按轮去重 `usage.record`，否则会漏扫会话或双倍统计 token。
- **Orca `location.workspaceId` 目录回退与 lease 心跳隔离**：Orca 桌面库 `agent_session_records.record_json` 常见省略 `launchDirectory`，`cwd` 需回退解析 `location.workspaceId` `<repoId>::<path>` 末尾路径；此外 `lease.lastRenewedAt` / `record_json.updatedAt` 会随窗口保活频繁刷新，`desktopSessions` 的 `revision` 与 `updatedAt` 必须锚定正文/轮次内容时间戳，防止闲置会话反复触发空扫描，并过滤 `role === "reasoning"` 项及为无助手文本的失败轮次合成错误回复。
