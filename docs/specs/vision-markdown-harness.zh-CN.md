# 核心构想：Markdown 即 Harness

> 这份文件记录这套东西的**出发点**，不是实现细节。实现见 `context-protocol.zh-CN.md`（契约）与 `harness-roadmap.zh-CN.md`（方向与落地记录）。

## 1. 命题

AI 生成或调用的东西，本质上都是 Markdown 文件：

| 产物 | 形态 | 谁写 |
| --- | --- | --- |
| 任务 / 派发载荷 | `.md` | 人写 + AI 补 |
| 规格 / 规则 | `.md` | 人写，AI 可整理 |
| 记忆 | `.md`（一文一条） | Dreaming 写，人改 |
| 技能 | 目录 + `SKILL.md` | 外部来源，库内只做卡片 |
| 结论 | 笔记里的列表块 | Agent 写，插件落 |

既然都是 Markdown，就应当满足三件事：**人能直接读、能直接改、改完立刻生效**。凡是做不到这三条的，都不是"一体化"，只是"能导出"。

## 2. 三条原则

1. **Markdown 是唯一正本**。视图（Base、看板、工作台）都是投影；删掉视图，数据不丢；改视图，数据跟着改；不存在"第二份真相"。
2. **双链管归处，块号管精确**。`[[笔记]]` 表达归属与关联；`[[笔记#^块号]]` 表达"就是这一段"。**行号是弱锚点**（实测 33 条记忆里 10 条行号已漂移），块号才是硬锚。
3. **每份 Markdown 都要有一条"生效路径"**。文件躺在库里不等于它有用：
   - 记忆 → 派发时按相关度注入
   - 技能 → 派发时给 `SKILL.md` 绝对路径
   - 任务 → 看板拖拽 / 派发
   - 规格 → 被引用时给全文路径

## 3. 四层结构

```
存储（都是 .md）        索引（都是投影）          生效（谁来读）           回写
Agent Deck/记忆/*.md  → 记忆.base / 记忆看板 / 索引.md → 注入（词面≥2、≤5条） → 💬 结论 / ⤴ 回链
Agent Deck/派发/*.md  → 派发-已改动.md              → 派发时给绝对路径        → status: dispatched
Agent Deck/任务/*.md  → 看板（taskBoardFiles）       → 派发 TODO（批量）       → 🔗 会话深链
技能/*.md             → 技能/索引.md                → SKILL.md 路径           → synced_at / edited
Agent Deck/工作台.md  → 唯一的入口索引                → 人看                    → 刷新命令
```

## 4. 与 RAG 的分野

**结构优先，检索兜底。**

用户手工标注的结构——缩进层级、列表序号、`domain`/`father`/`type`、块引用——是**人做过判断的注意力痕迹**，信噪比高于 embedding 相似度。所以：

- 先用结构遍历（大纲、双链、块号、frontmatter）；
- 词法/向量检索只在"我不知道它在哪"时兜底；
- **不存关联分数**，只存信号（显式边 > 共同来源 > 共同邻居 > 使用次数），每条关联都要能解释"为什么带它进来"。

## 5. 已落地（2026-11-18 批次，未发版）

- 记忆库一文一条 + Base/看板/逐条审阅三种读法 + 体检 + 来源块号与双向回链
- 记忆注入（相关度、预算、去噪）与 `agentText` 注入降噪
- 派发草稿（先看再发）+ 派发载荷（派发后快照）+ `anchor` 回指 + 归档
- 规划（目标 → task.md，产出即看板）+ 文件级看板（无母项也能合成根）
- 技能卡（134 个外部 Skill → 库内笔记，真实路径在 frontmatter）
- 工作台总览；管家 Agent 可配置
- 记忆索引（`记忆/索引.md`）

## 6. 还没做到

1. **运行时记忆查询**：Agent 遇到语义不详不能主动查，只能吃自动注入（最关键的缺口）；
2. **管家只做事后汇总**，不做中途干预；
3. **子代理不可见**（`parentSid` 已有数据，UI 未展示）；
4. **派发前草稿**已做，但**未在真实派发中跑通"改完草稿→点委派"**的完整闭环；
5. 技能卡是只读侧影，改卡片不会回写 `SKILL.md`；短链只支持单技能。

## 7. 红线

- 笔记正文只写 Obsidian 原生语法；自定义引用只活在机器侧
- 不静默丢上下文：任何裁剪/降级都必须声明
- 不把 AI 生成的内容当作用户说过的话（载荷不进通用记忆）
- 任务号 `^ad-*`/`^dsh-*` 注入前剥除；`^mem-*` 与 Obsidian 6 位号永不剥除
- 派发载荷是快照，不是可回改的草稿；草稿才是人改的那份
