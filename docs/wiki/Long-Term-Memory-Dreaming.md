# 长期记忆闭环（Dreaming）

Agent Deck 不只记录「今天 AI 干了什么」，还通过 **Dreaming** 把散落在日记与委派中的经验沉淀成可维护的长期记忆，再在未来派活时自动注入，形成完整闭环：

```text
日常干活 / 委派 → 自动记入日记 → Dreaming 提炼候选记忆 → 人工审阅确认 → 下次派活自动注入
```

## 1. 两种记忆库模式

在「设置 → Dreaming」中可选择存储模式（两者互斥，支持显式迁移）：

- **一文一条模式（推荐）**：每条记忆是 `Agent Deck/记忆/*.md` 下的独立 Markdown 文件，frontmatter 包含 `id / title / kind / type / state / date / sources`。
  - 可用 Obsidian **Base 表格**（`Agent Deck/记忆.base`）按类型与状态筛选排序。
  - 可在 **记忆看板** 里按状态三列拖拽管理。
  - 支持 **逐条审阅**（确认 / 拒绝）。
- **单文件模式**：集中写入 `Agent Deck/长期记忆.md`，严格保留你手写的前言与手工内容，仅更新 `<!-- ad:memory:start -->` 生成区块。

## 2. 溯源、Pin 提权与记忆体检

- **双向溯源**：每条记忆都附带来源日记的块号链接（`^mem-*`），Agent 注入后可回原文核对；被提炼的那一行日记也会获得反向回链。
- **关键记录提权**：在日记或视图里把某一轮记录 Pin 住（`<!-- ad-pin -->`）后，Dreaming 会优先把该条纳入提炼批次并提权。
- **记忆体检**：运行命令 `记忆：体检`，一键汇总无来源、待确认与疑似重复的记忆条目，方便定期清理。
- **记忆导入**：支持从 `.md / .json / .zip` 导入外部记忆，提供 0 Token 拆条或模型提炼两种方式。

## 3. 隐私边界与安全护栏

- **本地优先**：Dreaming 默认关闭，只有在你主动启用并触发时，才会把最近 14 天的相关记录发给你配置的本地 CLI 或 OpenAI 兼容模型。
- **`private` 隔离**：标记了 `private` 的笔记永远不会随派发或记忆提取外发。
- **离线安全回放**：可在 Dashboard 中一键回放近 7 / 30 天的历史工具调用，输出按高 / 中 / 低危分组的脱敏审计报告（`Agent Deck/安全审计.md`），并在 frontmatter 中维护白名单同步给实时 ACP 权限护栏。
