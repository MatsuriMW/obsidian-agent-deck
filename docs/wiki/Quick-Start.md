# 快速上手（Quick Start）

只需 3 分钟，即可把本机正在跑的 AI Agent 会话收拢到 Obsidian，并打通「笔记派活 → 自动回写日记」闭环。

## 1. 安装插件

- **社区插件市场**：打开 Obsidian「设置 → 第三方插件 → 社区插件市场 → 浏览」，搜索 **Agent Deck**，安装并启用。
- **手动安装**：前往 [GitHub Releases](https://github.com/MatsuriMW/obsidian-agent-deck/releases) 下载最新版的 `main.js`、`manifest.json`、`styles.css`，放入 `<你的库>/.obsidian/plugins/agent-deck/` 后在插件列表启用。
- 最低要求：Obsidian **1.4.0+** 桌面端（不支持移动端）。

## 2. 零依赖体验：先看住所有会话

首次启用时，插件会自动探测本机已安装的客户端，并默认关闭未安装项（不会产生无效扫描噪音）：

1. 打开右侧栏的 **Agent Deck 面板**。
2. 在 **「现在」** 视图中，你可以按 **项目 / 状态 / 列表** 查看正在运行、等待回复、需要确认或异常的会话。
3. 点击任意会话卡片即可查看只读对话详情、跳转回对应桌面端/终端，或拖到日记的任务行上直接绑定。
4. 打开 **协作回顾 Dashboard**，查看 Token 热力图、24 小时作息并发、Agent 与模型分布以及项目投入（全程纯本地读取，不联网、不调用模型）。

> **提示**：可以在设置中将最常用的 1–2 个客户端设为「主力 Agent」（读取全部历史；其余客户端仅扫描当天，兼顾速度与体积）。

## 3. 开启自动记日记

1. 在「设置 → 日记」中确认你的日记路径模板（与 Obsidian 日记或螺旋日程一致）。
2. 开启 **自动记日记** 并选择记录详略档位（简略 / 标准 / 详细）。
3. 之后当天各客户端的新会话会自动匹配或新建到日记的任务行下，同步状态（`DOING` / `TOREVIEW` / `DONE` 等）、活跃时段和每轮摘要；长篇回答会自动保存为独立文件并留短链。
4. 你手改过的任务标题和手写正文永远不会被插件覆盖。

## 4. 从笔记直接派活

在日记或任意笔记的任务行 / 段落里，有三种派活方式：

1. **行尾纸飞机**：点击光标所在段落末尾的纸飞机图标，在弹窗里预览正文与上下文、选项目目录和权限后发送。
2. **拖拽委派**：把列表项直接拖到右侧栏的某个 Agent 卡片上。
3. **行内 `@` / `/` 补全**：在任务行输入 `@` 选 Agent，输入 `/` 选模型与推理强度，直接触发。

派发后，后台进度、问答（`❓` / `✍️ 答：…`）与最终结论都会写回同一条任务下方。

## 5. 进阶功能推荐

- **原地分形看板**：任意包含多个子任务的块，行尾会出现「看板 N」，一键在当前笔记里展开看板。
- **macOS 菜单栏助手**：在设置中启用后，可用全局快捷键 `⌃⌥⌘D` 随时查看今日用量与待回复会话，并支持 Pin 置顶浮窗（需已安装 Xcode Command Line Tools）。
- **Dreaming 长期记忆**：在设置中按需开启，详见 [[长期记忆闭环（Dreaming）\|Long-Term-Memory-Dreaming]]。
