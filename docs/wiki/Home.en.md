# Agent Deck Wiki

> **A multi-client AI control deck with Markdown, outlines and journals as the single source of truth — plus a closed-loop long-term memory system.**

Welcome to the **Agent Deck** user documentation. Whether you are bringing your local AI agent sessions into Obsidian for the first time or building a full loop from daily journal delegation to Dreaming long-term memory, you can jump straight to the guide you need below.

## Core Positioning

- **Markdown, outlines & journals as the single source of truth**: Every tracked session record, task status, dispatch draft/snapshot, skill card, and long-term memory lives as plain Markdown in your Obsidian vault — no opaque proprietary database. Hand-edited titles and prose are never overwritten.
- **Multi-client control deck**: Unifies **17 built-in local agents + any Custom ACP CLI**, covering mainstream model families (**Claude, GPT / Codex, Gemini, DeepSeek, Qwen, MiniMax, Kimi, Doubao, Grok**, plus local Ollama) with dedicated local tracking and integration for Chinese agent clients (**DeepSeek Harness, MiniMax Code, QwenWork, Qoder, WorkBuddy, Kimi Code, Doubao Work**).
- **Closed-loop long-term memory**: Daily work is automatically logged to your journal, distilled by **Dreaming** into editable, source-linked memories, and automatically injected by relevance into future delegations.
